PROJECT AFTERLIGHT

Every abandoned machine has a story left to tell.

PROJECT AFTERLIGHT is a mobile-first 3D space archaeology adventure inspired by real space exploration and lunar science.

Mission 01: The Silent Moon

Explore a lunar research site as an astronaut and a robotic rover. Investigate Apollo-inspired scientific equipment, solve a fictional signal-restoration puzzle, and unlock a futuristic museum exhibit.

Core Features

- Cinematic space exploration
- Third-person astronaut gameplay
- Guided rover scanning
- Interactive artifact reconstruction
- Documented lunar science
- A fictional mystery connecting future missions

Technology

- Three.js
- HTML, CSS and JavaScript
- GitHub Codespaces
- GitHub Pages

Science and Fiction

Historical mission facts will be supported by reliable sources. Fictional repairs, simulated data and mystery clues will be clearly labelled as creative gameplay.

Project Goal

Build a lightweight, mobile-friendly game that can be explored and played in a web browser.
